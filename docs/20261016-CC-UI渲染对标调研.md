## 0. 阅读须知：坐标怎么用

- 明文模块：`claudecode283/modules/mXXXX_0xYYYYYYY.js`（已格式化，标识符仍是压缩名）。
- bytecode 区（渲染组件真正所在）：`claudecode283/claude.exe` 内的 JS 字符串常量，用字节偏移定位。
  搜法：`grep -a -o -b "<串>" claude.exe`，再用 `dd`/Python 取窗口（Git Bash 无 `strings`）。
- ⚠️ exe 含 Bun/JSC 引擎字符串表（≈65–88M），`to expand`/`●` 之类会命中**引擎噪声**（原生代码里的偶然字节）。
  CC 的 UI 字符串真正落在 **≈97–100M**（模块字符串池）与 **≈200–228M**（bytecode JS）两段。
  取窗口前先看偏移落在哪一段，别把噪声当证据。
- 本文件所有 `\uXXXX` 都是**源码里的转义写法**（明文模块 / bytecode 常量），不是终端显示字符；
  显示字符在括号里给出，例如 `\u23BF`（`⎿`）。

## 1. 结论速览（给复刻者）

1. **图标是一套「具名字形表」**，不是散落的 emoji。CC 把所有字形集中成一个对象
   （`m0052_0xbfaae5d.js`，bytecode 同款在 exe @201043800 附近），用语义名引用（`Z.arrowUp`、`Fr`、`yC`…）。
   复刻要点：**先建字形常量模块，再在渲染层按语义名引用**，不要到处硬编码字符。
2. **工具调用 = 一个 bullet 行**；bullet 随平台变：macOS `⏺`（`\u23FA`），其他平台 `●`（`\u25CF`）。
3. **工具结果 = 缩进 + `⎿` 前缀**（`\u23BF`），且**整体 dim**（`dimColor:!0`）；内容再缩进一档
   （`paddingLeft:3`）。这是 CC 执行流「一眼能分清"谁调用的、结果在哪"」的核心排版手法。
4. **折叠不是"隐藏"而是"锁定测量高度"**：一个 `Hj({lock:"always"|"offscreen"})` 组件在渲染后测量子内容行数，
   把可见高度锁住；转录模式（`ctrl+o`）再整体展开。
5. **折叠提示是动态键位**：`(ctrl+o to expand)` 里的 `ctrl+o` 来自键位表查询（`app:toggleTranscript`），
   **不是硬编码字符串**——用户改键位，提示会跟着变。
6. **spinner 是"字形帧 + 随机动词"**：帧序列 `· ✢ ✳ ✶ ✻ ✻`（+ 回弹），动词表 ~190 个（`spinnerVerbs`），
   文案形如 `✻ <Verb>… (esc to interrupt)`。
7. **"思考中"是独立一行**：`✻ Thinking…`（dim + italic），不是 spinner。

### 4.1 折叠组件 `Hj`（`m1277` 导出，源码原文）


**要点**：
- `lock:"always"`：每帧都重测；`lock:"offscreen"`（`Le` 用）：仅在不可见时锁高度（避免滚动抖动）。
- 高度 `minHeight` 由**渲染后测量**（`Xi(f.current).height`）得出 → 「折叠」= 用一个 `minHeight` 盒子
  把内容行数固定住，配合外层 `overflowY:"hidden"` 做截断。
- 组件 `y`/`u` 是「是否已在工具结果容器」的 context，避免重复套壳。

## 8. 复刻清单（最小可用集）

给 GA / 自研 agent 的落地顺序（按性价比）：

1. **建一个字形常量模块**（§2.1 的子集即可）：bullet `⏺/●`、结果前缀 `⎿`、spinner `✻`、
   树形 `├└│`、圆角框 `╭╮╰╯`、箭头 `↑↓→`、`▸`（折叠三角）。
2. **工具调用行**：`⏺ ToolName(摘要)`（bullet 平台自适应可选）。
3. **工具结果行**：`  ⎿  <内容>`，整体 dim；内容多行时缩进对齐。
4. **折叠**：给「工具输出 / 思考」块加 `collapsed` 状态 + `▸/▾` 标记 + 高度截断；
   折叠提示统一走**动态键位**（`(ctrl+o to expand)`），不要硬编码。
5. **spinner**：帧 `·✢✳✶✻` + 随机动词 + `(esc to interrupt)`；「思考中」另起一行 `✻ Thinking…`。
6. **转录/详情**：顶部状态行 dim；「全部展开/收起」一个键位。

**不需要复刻**：云端会话状态行（`remote_launched`）——【复刻时暂时不需要参考 claudecode 云端会话的实现】。
